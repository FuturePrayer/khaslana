## 2026-10-13 编辑器样式与主题适配

## 原生行为

- 新建模板使用 V2 文档编辑器。V1 原格式和原向导保留，可点「以 V2 编辑副本」另存；不会就地迁移原件。
- 输入变量置于步骤上方；展开说明可编辑显示名称、描述、必填属性及自定义变量。
- 一次展开一个步骤；支持上移、下移、复制、删除。复制 invoke 生成新标识并清空输出名，避免覆盖原步骤输出。
- 添加步骤可搜索 Git 操作、Skill、JavaScript；扩展步骤只提供 Skill 与 JS，MCP 作为步骤按需调用的工具，不再提供独立 MCP 创建入口。鼠标选择与搜索 Enter 使用同一组扩展候选。
- JS 显示脚本、输入及输出变量；Skill 显示名称、任务及输出变量。「调用工具（可选）」在未选择工具时默认收起，纯 JS 无需 MCP。展开后从按服务分组的菜单添加工具，不再单独选择服务；标签同时显示服务与工具名。已选工具默认展开，收起不清空权限。菜单只读取本地工具白名单与自动发现缓存，禁用服务不提供候选，运行时继续校验权限及真实 schema。
- 旧模板中的独立 `mcp.call` 保留编辑与执行兼容并显示提示，AI 生成不新增此类步骤。高级配置保留步骤标识、动作名、额外参数和页面守卫。未知 invoke 完整保存 with 对象。
- 可用变量栏在窗口逻辑宽度至少 1100px 时显示在右侧，较窄时移至内容底部。输出仅列出当前步骤之前产生的变量。
- 「检查模板」校验结构、唯一步骤标识、保留输出名及外部动作参数；显示保存内容。此检查不执行 Git、MCP、JS 或 Skill。保存后回到运行页，沿用实际输入、执行预览、权限确认、取消及日志链路。
- V2 的 AI 生成使用 V2 输出约束，并提供可用扩展名称；回填继续校验编辑会话。V1 编辑不会接受 AI 返回的 V2 扩展动作。
- 输入复用 Kit 宿主与动态字段路由；单行 Enter 提交，脚本／任务／JSON 等多行 Enter 换行、Ctrl+Enter 提交。步骤搜索 Enter 加入匹配项，Esc 先退出选择器，再退出编辑器。
- 编辑页仍沿用模态焦点圈；按实际绘制边界拦截背景鼠标操作。AI 思考浮层使用原有顶层模态与收尾机制。

## 实现范围与验收

新增模块 `src/workflow_editor/document.rs`、`src/workflow_editor/v2.rs`、`src/workflow_editor/visual.rs`，通过既有编辑器和工作流页接入；未改变执行器权限、网络代理、Git 写入或后台调度边界。没有引入 DAG、循环、定时任务或新脚本运行器。

原生运行页复用现有输入／预览／日志组件，增加编辑入口及中文页面名。设计中的预览入口在原生编辑页呈现为「检查模板」，实际执行预览由保存后的运行页负责。

历史验收范围与计数仅记录当时结果；本轮实机检查和未覆盖项以「2026-10-13 编辑器样式与主题适配」中的记录为准。完整验收矩阵仍有 DPI、IME 等未完成项，不能宣称全部通过。
