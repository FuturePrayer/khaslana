# 创建 release 分支并自动提交表单

此演示使用 Selenium 的公开测试表单，不连接截图中的业务系统。无需 AI 供应商。

1. 安装 Microsoft Edge。在工作流页面选择 `create-release-submit.json5`，或复制到模板目录后刷新。
2. 首次使用内置浏览器组件时点击“下载并启用”。组件已就绪后，纯 JS 与内置 Edge 流程不显示运行授权弹窗。
3. 在运行配置中确认分支起点和 release 分支名，填写多行变更说明，选择演示选项及完成日期。
4. 点击运行：创建并切换分支，核对分支，组织摘要，填写网页、逐项读取实际值复核，最后自动提交一次。

演示选项的实际值为 `1`、`2`、`3`，对应网页的 One、Two、Three。日期参数使用 `YYYY-MM-DD`，JS 转换为演示网页要求的 `MM/DD/YYYY`。分支和摘要直接通过工作流变量传递，不使用剪贴板。

只有结果页出现 `Form submitted` 和 `Received!` 才算成功。填写完成后生成一张临时截图，工作流结束时会连同结构快照自动删除；下载及其它导出文件保留。结果保存为 `${formResult}`。

请在测试仓库演练。工作区必须干净，目标分支不能已存在；此模板不合并、不推送。浏览器失败不回滚已经创建的分支，提交结果不明确时不自动重试。排查后重新运行应使用新的分支名，避免原样重跑已完成的创建操作。
